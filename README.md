### Telemetry: a team app for FTC robotics teams

[App Store](https://apps.apple.com/us/app/telemetry-by-13115/id6830405761) · [Web app](https://13115robotics.com/telemetry/)

- An iPhone, Android and web app (Flutter) that any FTC team can use: tasks, match alerts at meets, offline scouting, a calendar, and tools for inventory, budget and an engineering log.
- A multi-team backend on Supabase (TypeScript, PostgreSQL) with owner-approved team registration, role-based permissions and per-team data isolation, covered by 400+ automated tests.
- An AI assistant that answers from the team's own data with on-device models, so questions stay on the device.
- The source is private because it holds teams' data. I'm happy to give a walkthrough.
